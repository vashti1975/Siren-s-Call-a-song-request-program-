SONGBOOK SYNC — SOURCE STARTER

Build the companion on Windows using .NET 10 and your installed Dalamud libraries:
  dotnet build SongbookSync.csproj -c Release -p:DalamudLibPath="C:\path\to\Dalamud"

Install the built SongbookSync.dll with SongbookSync.json in a permanent folder. In /xlsettings > Experimental > Dev Plugin Locations, add the DLL path. Enable it in /xlplugins > Dev Tools. Install only on the lead bard, with MidiBard 2 enabled.

Open your deployed songbook, expand MidiBard Sync, generate a connection key and copy the full command:
  /songbooksync https://YOUR-SONGBOOK-HOST TOKEN

The website URL is configurable; no personal or production website is hardcoded. HTTPS is required. Keep the key private.

/s covers requested/named/ordinary announcements. Commands:
  /songbooksync status
  /songbooksync announcements off
  /songbooksync announcements on
  /songbooksync disconnect

The owner website can omit requester names from say announcements and revoke keys. Filename matches are created for your own songs after pairing. No MIDI music or song list is provided.

Source targets Dalamud API 15 and .NET 10. Rebuild/adapt for later game/plugin versions if needed. Actual loading and chat delivery must be tested in the user's Windows client.
