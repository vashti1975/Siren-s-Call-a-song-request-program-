SIREN'S CALL SONG REQUEST BOOK — DALAMUD COMPANION

Version 1.2.0, internal ID SongbookSync. Requires MidiBard 2 on the lead bard
and a hosted songbook. The website remains the listener request page.

NORMAL INSTALLER (after a compiled release is tested and publicly hosted)
1. Add the published pluginmaster.json URL in /xlsettings > Experimental >
   Custom Plugin Repositories. A private GitHub source URL will not work.
2. Find Siren's Call Song Request Book in /xlplugins and install it.
3. Generate a connection key in your owner songbook, then copy its full command:
   /songbooksync https://YOUR-SONGBOOK-HOST TOKEN

MIGRATING FROM A DEV PLUGIN
Before removing or disabling anything, keep a backup of your connection.json
in the SongbookSync plugin configuration folder. Do not post this file: it
contains your pairing key. Disable the old Dev Tools instance and remove its
Dev Plugin Locations entry so that only one instance runs. Install the normal
release, check /songbooksync status and re-pair from your owner page if needed.
The internal plugin ID and command stay unchanged. Keep your old files until
one-song playback, request clearing and announcements have been tested.

SOURCE BUILD (for maintainers)
Install .NET 10 SDK and run FFXIV with Dalamud at least once, then from this
bridge directory: dotnet build SongbookSync.csproj -c Release
The official Dalamud.NET.Sdk/15.0.0 generates SongbookSync/latest.zip under
bin. To use a custom library folder, set DALAMUD_HOME or pass
-p:DalamudLibPath="C:\path\to\Dalamud".

The GitHub workflow builds on Windows and retains a private artifact. It does
not publish files, make the repository public or provide an installer URL.
See docs/PLUGIN-INSTALLER.md in the repository for packaging and release steps.
The source ZIP is source code, not the ZIP installed through Dalamud.

Commands: /songbooksync status; /songbooksync announcements on;
/songbooksync announcements off; /songbooksync disconnect
Website Disconnect revokes the server key. HTTPS is required for pairing.
No songs, music files, saved matches or real pairing keys are included.
