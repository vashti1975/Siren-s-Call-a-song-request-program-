# Basic FFXIV Songbook

Reusable application with an empty catalog, neutral colors and a generic moogle chibi. Personal songs, lists, saved filename matches, branding and account grants are excluded.

See [setup](SETUP.md), [features](FEATURES.md), [customization](docs/CUSTOMIZATION.md), [architecture](docs/ARCHITECTURE.md) and [companion](docs/MIDIBARD.md). Tests use invented fixtures only; production starts empty.
